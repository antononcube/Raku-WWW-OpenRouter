# WWW::OpenRouter

Raku package that provides access to the LLMs of [OpenRouter](https://openrouter.ai).

Closely follows of the designs of 
["WWW::OpenAI"](https://github.com/antononcube/Raku-WWW-OpenAI),
["WWW::OpenAI"](https://github.com/antononcube/Raku-WWW-MistralAI), and
["WWW::OpenAI"](https://github.com/antononcube/Raku-WWW-Gemini).
